# Form/checklist pilot decision (#48)

Decision: no-go until a pilot supplies the actual required forms, deadlines and
status authorities. No universal nonprofit checklist, document collection or
compliance certification is implied. No implementation issue is created prematurely.

For each supplied requirement, record the authoritative form/version, applicable
roles/activity, exact deadline/timezone, authorized status source, responsible
reviewer, reminder scope and retention/access rules. Distinguish not requested,
requested, received, reviewer-confirmed and disputed; receipt alone is not validation.

Bounded MVP if justified: an owner-visible status checklist with source citations
and authorized reminders. Avoid storing full signed forms where an authoritative
external status reference suffices. Exclude legal conclusions, signature validation,
identity certification and automated compliance claims. Acceptance must include a
changed deadline, revoked access, disputed status and deletion according to the
supplied retention policy. Requirements remain missing, not inferred from examples.
